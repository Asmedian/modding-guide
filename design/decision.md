# Approved visual direction

The implementation follows the supplied desktop and mobile concepts:

- dark graphite-blue background with restrained bronze-gold accents;
- readable serif display headings and neutral sans-serif body copy;
- sticky desktop header, curated left navigation, central article, and right-page outline;
- compact mobile header, full-width search, drawer navigation, and stacked cards;
- subtle rune-like geometric ornaments without shipping unverified game artwork;
- a warm parchment-and-bronze light theme using the same layout and tokens.

The concept cards for ERM Scripts and Plugins are not implemented in this phase. The documentation card expands into the only active top-level section until those phases begin.

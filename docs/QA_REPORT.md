# Проверка фундамента сайта — 4 сентября 2026

Исторический отчёт предыдущего этапа. Новое наполнение ERM и проверки его интерфейса описаны в [ERM_CONTENT_AUDIT.md](ERM_CONTENT_AUDIT.md); перечисленные ниже браузерные проверки не распространяются на новый интерфейс ERM.

## Реализовано

- Исправлены реактивные ссылки при RU/EN-переходе, сохранение текущей статьи/якоря и обработка базового пути GitHub Pages. Обновляется и `html.lang`.
- Верхнее меню выровнено, добавлены ERA `icon.png`, разделитель, GitHub, неактивные ERM Scripts/Plugins и выпадающий список языков. На узком экране эти действия доступны через меню.
- Поиск — немодальный выпадающий блок с подсветкой видимого фрагмента. Точный индекс объединён с Pagefind; совпадения по формам слов сохраняют подсветку. Поиск на странице работает в том же блоке, имеет все совпадения, счётчик и переходы вперёд/назад с прокруткой статьи.
- Центральный фон затемнён и заполняет всю ширину между боковыми панелями; ограничение ширины перенесено во внутренний контейнер текста. Подпись сообщества заменена на запрошенную, `shield-glyph` удалён только из правой карточки быстрого старта.
- Документация содержит 16 статей в двух локалях, включая создание и совместимость модов, загрузку ресурсов, диагностику и каталог фактически установленного комплекта ERA Tools.
- Добавлены CMS-конфигурация, автоматическая LLM-карта, генерация машинных URL с учётом размещения в подпапке, JSON Schema checks и проверки итогового HTML/источников/навигации.

## Результаты

- `npm test`: 30/30 (включая правила закрытия поиска, сохранение запроса/области, literal matching RU/EN, переходы по совпадениям, восстановление исходных текстовых узлов и переключатель языка).
- `npm run build`: успешно, Svelte check — 0 ошибок, 0 предупреждений.
- Финальный статический валидатор: 32 локализованные статьи, 2062 ссылки, 318 якорей.
- Отдельная сборка с тестовым `BASE_PATH=/era-modding-guide` успешно проверена; исправлена обнаруженная ошибка удвоения префикса.
- В браузере проверены RU→EN с сохранением `#archives`, немедленное обновление sidebar, поиск `MMArchive`, морфологические запросы `архивами` и `archived`, переход на найденную секцию, локальный поиск `archive` (5 совпадений, переход 1/5→2/5), мобильное меню и поиск на ширине 390 px.
- Для повторного сообщения `VM155 ... reportAllChanges ... startTime` найден [web-vitals #792](https://github.com/GoogleChrome/web-vitals/issues/792): совпадают все позиции стека, включая `2:19429` и `2:5652`. В отчёте описан внедрённый Chrome DevTools скрипт, падающий при soft navigation. `reportAllChanges` отсутствует в исходниках, установленных зависимостях и сборке этого сайта. Это сильное указание на тот же внешний дефект, а не прямой перехват скрипта из браузера пользователя.
- Добавлен локальный обход: только пункты выбора языка используют `data-sveltekit-reload`; остальные внутренние ссылки сохраняют клиентскую навигацию. Проверены 6 последовательных переходов RU↔EN с сохранением `/docs/quick-start/#skeleton`, правильными заголовками и пустым журналом ошибок/предупреждений тестовой вкладки. Исходный сбой DevTools в доступном тестовом браузере не воспроизводится; обход не является исправлением самого Chrome.
- До последующего ограничения общей ширины на окне 2560 px DOM-измерения подтвердили смыкание колонок; на мобильной ширине 390 px горизонтальной прокрутки не было. В правой карточке 0 элементов `.shield-glyph`. Эти браузерные измерения относятся к предыдущей версии компоновки.

## Уточнение ширины сайта и шапки

- Позднейшая настройка компоновки увеличила максимальную ширину единого `site-frame` до 1920 px и расширила обе боковые колонки; центральный фон по-прежнему заполняет расстояние между ними внутри рамки.
- Шапка переведена с жёстких колонок Grid на Flex: название сайта, навигация и действия сохраняют естественную ширину, поиск сжимается независимо от длины текста. Компактные отступы включаются при 1440 px; мобильный вариант по-прежнему включается при 1200 px. Подпись поиска сокращается, значок и сочетание клавиш не сжимаются и не переносятся.
- Новые проверки подтверждают структуру общей рамки, отсутствие обрезающего overflow у её контейнера и правила сжатия шапки. Повторная визуальная проверка этой версии в браузере не выполнялась.

## Границы готовности

- Текущие изменения поиска покрыты модульными проверками; DOM-адаптер тестирует выделение и восстановление узлов, но не заменяет браузерную проверку кликов и прокрутки. Новый браузерный прогон этого изменения не выполнялся.

- На описанном здесь этапе ERM Scripts, обучение ERM, Plugins, NH3API и Lua были отложены. Затем пользователь активировал справочник ERM и отдельным этапом раздел Plugins с NH3API; обучение остаётся пустым, Lua — отложенным.
- Репозиторий GitHub и конечный Pages URL не предоставлены: GitHub-кнопка ведёт на главную GitHub, публичное развёртывание не выполнялось.
- Реальный Windows 7 + Chrome 109 smoke-test, дополнительные браузеры из полной матрицы плана, выбор основной версии ERA и окончательное подтверждение прав на внешние материалы остаются условиями релиза. Автоматические проверки baseline не заменяют реальный браузерный прогон.

Локальный просмотр готового артефакта: `npm run preview`. Этот сервер обслуживает `build/` вместе с Pagefind, в отличие от промежуточного вывода SvelteKit.

## Как использовать {#usage}

В запросе к ИИ используйте [английскую точку входа](../../../en/docs/llm-map/). Она ведёт к [протоколу и карте](../../../llm/browse/index.json) и [единому английскому каталогу](../../../llm/browse/en/index.md). Краткая альтернативная точка входа — [llms.txt](../../../llms.txt).

Все файлы для LLM публикуются только на английском, чтобы не тратить контекст на дублирующие переводы. Модель может отвечать на языке вашего запроса. Исходные имена файлов, локаторы, технические обозначения и строки внутри кода сохраняются без изменений.

Порядок поиска: **раздел → тема → страница каталога → нужные части полного текста**. Не загружайте весь сайт. Связанные тексты объединены примерно по 24 КБ; каждый файл каталога ограничен 48 КБ. Крупные статьи разделены на последовательные части, примеры кода остаются целыми.

## Выбор разделов {#sections}

| Задача | Английский каталог |
| --- | --- |
| Установка ERA, структура мода, совместимость, загрузка ресурсов, инструменты | [Docs](../../../llm/browse/en/docs/index.json) |
| Синтаксис ERM, переменные, триггеры, ресиверы, таблицы ID, Framework | [ERM](../../../llm/browse/en/erm/index.json) |
| Нативные плагины, C++, хуки, ERA API, H3API, NH3API | [Plugins](../../../llm/browse/en/plugins/index.json) |
| DEF, изображения, звуки, видео, шрифты, палитры и кампании SoD | [Wiki](../../../llm/browse/en/wiki/index.json) |

Для задач на стыке нескольких областей прочитайте каждый нужный раздел. Например, моду с существом могут понадобиться ERM-контракты и таблицы ID, ресурсы Wiki и документация по упаковке мода. Для C++-расширения могут потребоваться плагины, API и ERM-события. Lua пока отложен; обучение ERM содержит введение в работу с ИИ.

## Поиск точного имени {#lookup}

- [Команды, события, функции и константы ERM](../../../llm/browse/symbols/index.json): выберите семейство и диапазон имени. Записи ведут к точным якорям и английским текстовым частям.
- [Файлы Wiki](../../../llm/browse/wiki-resources/index.json): выберите редакцию, тип и диапазон имени без учёта регистра. Сохранены архив, размер, SHA-256, английские категории и страницы, оригиналы и производные файлы. TXT пока не импортированы.
- [Реестры ERM](../../../llm/browse/reference/index.json): алфавит, ресиверы, события, функции, глобальные переменные, константы, старые команды, ссылки и иллюстрации.
- [Источники](../../../llm/browse/sources/index.json): найдите ID из `sourceRefs` и `sectionSources`; проверьте версии, локаторы и контрольные суммы.

## Порядок чтения и ответа {#reading}

1. Определите задачу, версию ERA и нужные разделы. Выберите темы по английским названиям и ключевым словам.
2. Индекс темы ведёт к страницам каталога. У статьи есть стабильный `id`, английский канонический `url`, описание, вопросы, ключевые слова, `previous` / `next`, источники и упорядоченные `parts`.
3. Откройте нужные текстовые части. Один файл может содержать несколько статей: выбирайте по ID и номеру части. `fromAnchor`, `toAnchor` и заголовки помогают найти фрагмент. Прочитайте все продолжения нужного контракта.
4. Между `llm:body` и `llm:end` находится полный исходный фрагмент. Соединение частей по порядку без служебных переводов строк восстанавливает статью. Сохранены код, таблицы, ссылки, иллюстрации и скрытые комментарии. Относительные ссылки разрешайте от канонического URL статьи.
5. Следуйте связям в другие темы и разделы. Проверяйте источники конкретного раздела, версии, области видимости переменных и совместимость.
6. Отвечайте со ссылками на канонические страницы и точные якоря. Разделяйте подтверждённое справкой, допущения и фактическую проверку в игре. Если ссылки недоступны, попросите конкретные файлы.

## Как читать каталог {#usage}

Названия ниже соответствуют каталогам и исполняемым файлам установленного комплекта ERA Tools. Описание приводится только там, где его подтверждает встроенная справка, метаданные EXE или состав поставки. Наличие программы не гарантирует совместимость с каждой версией ERA и Windows: работайте на копии игры и сохраняйте исходный файл.

## Моды, редактор и диагностика {#modding}

| Инструмент | Назначение и примечание |
| --- | --- |
| **Mod Manager / SD Mod Manager** | Управление набором модов и их порядком. Встроенная документация описывает `mod.json`, локализуемые поля и `requires`, `load_after`, `incompatible`. В комплекте есть основная, старая и тёмная сборки; не смешивайте их настройки. |
| **Erm_Editor_Sublime** | Поставляемая конфигурация Sublime Text с пакетами для ERM. Сам справочник ERM отложен, но редактор остаётся рабочим местом для текстов сценариев. |
| **Issue Wizard** | В поставке присутствует `Issue Wizard.exe` и настройки репозитория. Используйте конкретную инструкцию вашей сборки; публичная документация комплекта не описывает его протокол полностью. |
| **DebugCreator** | Каталог содержит `DebugCreator.hta` и файл настроек. Назначение и совместимость в поставке не документированы достаточно подробно для пошаговой инструкции. |
| **VfsTest** | Отдельный `VfsTest.exe` с тестовыми каталогами. Это специализированная проверочная утилита; запускайте её только на копии установки и сверяйте с версией ERA. |
| **Autoit** | Среда выполнения AutoIt, используемая некоторыми вспомогательными сценариями комплекта. Это не редактор игрового формата. |

## Архивы и таблицы {#archives-tables}

| Инструмент | Назначение и примечание |
| --- | --- |
| **MMArchive 1.3.1** | Редактирует архивы Might & Magic 6–8 и Heroes III, кроме `*.hwl`. Умеет добавлять файлы, объединять архивы и оптимизировать их после замен/удалений. Для VID встроенная оптимизация особенно важна перед использованием других программ. |
| **Txt Tables Editor 1.4.1** (`TextEdit/TxtEdit.exe`) | Редактор табличных TXT-ресурсов. Сохраняйте исходную кодировку, число колонок и разделители. |
| **Object TXT Files Editor 1.5** (`ObjTxtEditor/objtxteditor.exe`) | По метаданным EXE — редактор файлов `object` Heroes III. Проверяйте результат на одной копии таблицы. |
| **lodexport.exe / lodimport.exe / lodmerge.exe** | Отдельные консольные утилиты поставки для операций с LOD. Локальная поставка не содержит рядом достаточной справки, поэтому для новых задач предпочтительнее документированный MMArchive. |
| **resman.exe / repman.exe / objector.exe** | Унаследованные отдельные утилиты в корне Tools. Их интерфейсы и допустимые версии входов в комплекте не описаны; не применяйте к единственной копии ресурса. |

| --- | --- |
| **Def Preview 1.0** | Просмотр анимации выбранной группы DEF. Встроенная справка также описывает переименование групп, изменение типа DEF через строку состояния и загрузку номеров групп из другого DEF. |
| **Heroes3 Def Tool 3.2.1** (`H3DefTool`) | Сборка и редактирование DEF, кадров, масок и теней. Встроенный учебник описывает создание нового DEF и резервные копии; всегда проверяйте палитру и индексы кадров. |
| **DEFka 2.0** | Отдельная программа для работы с наборами графики существ. Поставка содержит базу данных и служебные текстовые файлы, но не даёт полной современной спецификации формата. |
| **Heroes 3 Dialogs** (`Dialogs Editor`) | Метаданные EXE называют программу редактором пользовательских диалогов WoG. ERM-механизм диалогов будет описан позже; здесь фиксируется только назначение инструмента. |
| **FNT Editor / FNTeditor** (`Font Editor`) | Две поставляемые версии редактора игровых шрифтов. Не перезаписывайте единственный FNT-файл и проверяйте полный набор символов обеих локалей. |
| **PngCrush** | Поставка `pngcrush.exe` и командного файла для оптимизации PNG. Оптимизация не исправляет неверный путь, размер или семантику прозрачности. |

## Карты и шаблоны {#maps}

**Template Editor 0.99** (`TEditor`) работает с шаблонами генератора случайных карт. Его справка описывает создание и импорт шаблонов из `rmg.txt`, зоны, переходы, условия существования, охрану и файлы проекта `.tpz`. Для импорта встроенных шаблонов требуется извлечённый `rmg.txt` из `h3bitmap.lod`.

Каталог **ExeMapCompiler** содержит сценарии `compile.phc`, `decompile.phc`, `optimize.phc` и `mapToDbgmap.bat`; пошаговая справка в поставке отсутствует. Используйте только в процессе, где формат входа уже подтверждён.

## Патчи и специализированные конвертеры {#patches}

| Инструмент | Назначение и уровень риска |
| --- | --- |
| **BinMagic 1.0** | Создаёт, преобразует и применяет текстовые или бинарные патчи. Поддерживает преобразование адресов через DLL. Ошибка адреса или версии повреждает целевой файл — всегда работайте с копией. |
| **ExeBuilder** | Берёт `in.exe`, применяет все найденные рядом `*.bin` и создаёт `out.exe`. Справка состоит из этой краткой схемы; не используйте результат с другой версией EXE. |
| **EVME 1.0 / ERM Vars Memory Editor** | Отладчик переменных и памяти запущенной игры для старых линий WoG/TE/Phoenix. Встроенная справка прямо предупреждает об опасных операциях записи памяти и дампов; для современной сборки совместимость не предполагается. |
| **UN:C to bin patch converter** | Преобразует последовательность записей `C[address]/size/value` в один BIN-патч. Это инструмент бинарных адресов; подробности UN:C отложены вместе с разделом ERM. |
| **ScriptsToEra260** | Каталог конвертера сценариев с PHP-скриптом и таблицей именованных функций. Пошаговое применение относится к будущей ERM-документации. |
| **installmod.exe** | Корневая утилита установки мода. Публичной встроенной справки рядом нет; Mod Manager предпочтительнее для контролируемого процесса. |

## Правило безопасного выбора {#safety}

Сначала выберите формат, затем инструмент, затем способ проверки. Сохраните оригинал, выполните одно действие, сравните результат и только после запуска в игре переходите к пакетной обработке. Для утилит без встроенной справки каталог подтверждает наличие, но не даёт права угадывать ключи командной строки или совместимость.

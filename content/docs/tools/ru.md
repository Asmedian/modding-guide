## Начинайте с формата {#choose}

Инструмент выбирают не по известности, а по паре «вход → выход». Запишите имя и формат исходного файла, ожидаемый результат, версию программы и способ проверки в игре. Если эти четыре пункта неизвестны, запуск старой утилиты создаёт больше неопределённости, чем пользы.

Комплект ERA содержит современные и унаследованные программы рядом. Одинаковая задача может иметь несколько решений: например, архивы обрабатываются MMArchive и отдельными `lod*.exe`, а шрифты — двумя версиями Font Editor. Для нового процесса выбирайте вариант с понятной встроенной справкой и обратимой операцией.

## Рабочая цепочка по типу данных {#workflow}

| Задача | Основной инструмент | Независимая проверка |
| --- | --- | --- |
| LOD/PAC/VID и связанные архивы | MMArchive | извлечение, обратный импорт, сравнение и запуск |
| Просмотр DEF | Def Preview | группы, кадры и тип DEF |
| Сборка DEF | Heroes3 Def Tool | повторное открытие и проверка в игре |
| TXT-таблицы | Txt Tables Editor | кодировка, колонки, разделители |
| Файлы `object` | Object TXT Files Editor | одна скопированная таблица и тестовая карта |
| Шаблоны случайных карт | Template Editor | экспорт/импорт `rmg.txt` и генерация карты |
| BIK/SMK | RS Bink Player | воспроизведение и покадровый просмотр |
| Список и порядок модов | SD Mod Manager | контрольный запуск и проверка владельца ресурса |

Подробные названия всех каталогов и исполняемых файлов находятся в [каталоге инструментов](catalog/).

## Архивы требуют round-trip {#archives}

MMArchive документирует добавление файлов, объединение архивов и оптимизацию. Замена и удаление создают фрагментацию; для VID программа хранит дополнительную информацию о размерах, которую другие инструменты могут не распознать до оптимизации.

Перед массовым изменением извлеките один ресурс, импортируйте его без смысловой правки и сравните результат. Успешный round-trip подтверждает только техническую цепочку — после него всё равно нужен запуск игры.

## Графика, палитры и интерфейс {#graphics}

Def Preview подходит для быстрого просмотра анимационных групп. Heroes3 Def Tool предназначен для сборки и редактирования DEF, включая кадры, маски и тени. DEFka поставляется отдельно для графики существ, а Heroes 3 Dialogs — как редактор пользовательских диалогов WoG. Font Editor представлен двумя версиями.

Не переносите параметры «по похожей картинке». Размеры, индекс группы, номер кадра, палитра и прозрачность являются частью ресурса. PngCrush уменьшает PNG, но не исправляет неверный путь или смысл альфа-канала.

## Инструменты повышенного риска {#risk}

BinMagic, ExeBuilder, EVME и UN:C to BIN работают с патчами, исполняемым файлом или памятью процесса. Их результат зависит от конкретной версии EXE и может повредить файл или запущенную игру. Этот сайт пока не публикует инструкции ERM/UN:C: наличие утилиты в комплекте не означает, что адрес или рецепт подходит текущей сборке.

Используйте копию, храните контрольную сумму оригинала и никогда не применяйте неизвестный патч «для проверки». EVME прямо описывает потенциально опасные операции записи памяти и дампа.

## Безопасный процесс {#safe-process}

1. Скопируйте исходник и зафиксируйте его SHA-256.
2. Выполните одну операцию одним инструментом.
3. Сохраните экспорт отдельно от редактируемого исходника.
4. Откройте результат второй программой, если формат это допускает.
5. Проверьте один повторяемый сценарий в отдельной установке игры.
6. Только после этого обрабатывайте пакет файлов.

Если встроенной справки нет, ограничьтесь инвентаризацией программы и найдите подтверждённую документацию для точной версии. Не угадывайте параметры командной строки по имени EXE.

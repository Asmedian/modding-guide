## Платформа и проект {#platform}

| English | Русский | Значение |
| --- | --- | --- |
| ERA platform | платформа ERA | Набор расширений и механизмов загрузки вокруг Heroes III/WoG. |
| mod | мод | Отдельный набор данных и поведения, подключаемый к игре. |
| mod directory | каталог мода | Корневой каталог конкретного мода внутри `Mods`. |
| game root | корень игры | Каталог установки Heroes III, относительно которого описываются пути. |

## Ресурсы {#resources}

| English | Русский | Значение |
| --- | --- | --- |
| resource | ресурс | Именованные данные, которые игра загружает: изображение, текст, звук и т. п. |
| loose file | свободный файл | Файл в обычном каталоге, а не внутри архива. |
| archive | архив | Контейнер ресурсов, например LOD или PAC. |
| redirection | перенаправление | Правило, которое связывает запрошенное имя ресурса с другим путём. |
| load order | порядок загрузки | Последовательность, влияющая на выбор ресурса при совпадении имён. |

## Технические термины {#technical}

`LOD`, `PAC`, `DEF`, `TXT`, `JSON`, `ERT`, `ERS`, `PNG`, `WAV` и имена каталогов не переводятся. В русском тексте допустимо склонять родовое слово: «архив PAC», «кадр DEF», «файл JSON».

Термины `trigger`, `receiver` и `ERM command` зарезервированы для будущего раздела ERM; их технические коды также не переводятся.

## Задача и применимость {#purpose}

Для чистого h3wog.exe: существа 2..197, таблица по одному байту. Пример только читает значение.

## Код {#code}

```erm
!?FU(MyMod_ReadProjectile);
!#VA(creature:x) (result:x);
!!VR(result):S16;
!!FU|(creature)<2/(creature)>197:E;
!!UN:C7961526/(creature)/1/?(result);
```

## Версия и ограничения {#limits}

Адрес подтверждён историческим рецептом для WoG/ERA на базе h3wog.exe. Он не проверен выполнением в установленной игре и не гарантирован для другого EXE или плагина. Перед применением проверьте сборку и исходные байты; модификации исполняемого кода могут переживать смену карты. Тип 16 требует DEF с пустым именем; отсутствие ресурса вызывает сбой при выстреле. Формула исходного автора: creature + 7961526. Автор рецепта — Chortos-2, опубликовано Ivor; ограничения взяты из разрешённого сообщения 70514.

## Назначение {#purpose}

Форматирует количество с локалью и суффиксами K/M/G. maxLen по умолчанию 5 логических символов, maxDigits — 4; поддерживает отрицательные числа.

## Контракт вызова {#signature}

```erm
!!FU(FormatQuantity):P(value)/(resultPtr)/(maxLen)/(maxDigits);
```

## Порядок параметров {#parameters}

| Позиция | Имя в исходнике | Использование |
| --- | --- | --- |
| x1 | `value` | вход |
| x2 | `resultPtr` | выход / изменяемый |
| x3 | `maxLen` | выход / изменяемый |
| x4 | `maxDigits` | выход / изменяемый |

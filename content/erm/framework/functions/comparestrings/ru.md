## Назначение {#purpose}

Сравнивает две ERM-строки операторами языка и возвращает -1, 0 или 1.

## Контракт вызова {#signature}

```erm
!!FU(CompareStrings):P(str1Ptr)/(str2Ptr)/(result);
```

## Порядок параметров {#parameters}

| Позиция | Имя в исходнике | Использование |
| --- | --- | --- |
| x1 | `str1Ptr` | вход |
| x2 | `str2Ptr` | вход |
| x3 | `result` | выход / изменяемый |

## Состояние и зависимости {#context}

Именованные глобальные переменные в теле не используются.

## Версия и статус {#provenance}

Статус: `public`. Исследован полный блок `lib/9999 era - stdlib.erm`, строки 1431–1442. Заголовок Framework требует ERA 3.9.15+. Поведение описано по этому снимку; игровое выполнение примеров отдельно не проверялось.

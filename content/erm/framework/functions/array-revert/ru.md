## Назначение {#purpose}

Разворачивает порядок элементов всего массива либо включительного диапазона. По умолчанию 0..size-1; поддерживает числа и строки.

## Контракт вызова {#signature}

```erm
!!FU(Array_Revert):P(list)/(startInd)/(endInd);
```

## Порядок параметров {#parameters}

| Позиция | Имя в исходнике | Использование |
| --- | --- | --- |
| x1 | `list` | вход |
| x2 | `startInd` | выход / изменяемый |
| x3 | `endInd` | выход / изменяемый |

## Состояние и зависимости {#context}

Именованные глобальные переменные в теле не используются.

Вызовы экспорта: `Erm_RevertInt32Array`.

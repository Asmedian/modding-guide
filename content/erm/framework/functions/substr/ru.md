## Назначение {#purpose}

Возвращает подстроку: start с нуля, отрицательный start от конца; count — длина, отрицательный count исключает хвост.

## Контракт вызова {#signature}

```erm
!!FU(Substr):P(strPtr)/(start)/(count)/(result);
```

## Порядок параметров {#parameters}

| Позиция | Имя в исходнике | Использование |
| --- | --- | --- |
| x1 | `strPtr` | вход |
| x2 | `start` | вход |
| x3 | `count` | вход |
| x4 | `result` | выход / изменяемый |

## Состояние и зависимости {#context}

Именованные глобальные переменные в теле не используются.

Вызовы экспорта: `Erm_Substr`.

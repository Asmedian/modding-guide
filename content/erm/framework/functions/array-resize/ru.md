## Назначение {#purpose}

Изменяет размер массива. Новые элементы получают 0/пустую строку или указанный fillValue; существующие сохраняются, усечённые удаляются.

## Контракт вызова {#signature}

```erm
!!FU(Array_Resize):P(list)/(newSize)/(fillValue);
```

## Порядок параметров {#parameters}

| Позиция | Имя в исходнике | Использование |
| --- | --- | --- |
| x1 | `list` | вход |
| x2 | `newSize` | вход |
| x3 | `fillValue` | вход |

## Состояние и зависимости {#context}

Именованные глобальные переменные в теле не используются.

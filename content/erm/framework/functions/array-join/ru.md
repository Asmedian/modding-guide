## Назначение {#purpose}

Соединяет элементы целого или строкового массива, разделяя gluePtr (по умолчанию пустой строкой). Возвращает ERM-строку; использует и очищает s^result^ и s^temp^.

## Контракт вызова {#signature}

```erm
!!FU(Array_Join):P(list)/(resultPtr)/(gluePtr);
```

## Порядок параметров {#parameters}

| Позиция | Имя в исходнике | Использование |
| --- | --- | --- |
| x1 | `list` | вход |
| x2 | `resultPtr` | выход / изменяемый |
| x3 | `gluePtr` | выход / изменяемый |

## Состояние и зависимости {#context}

Глобальные переменные: [s^temp^](../../globals/#global-s-temp) · [s^result^](../../globals/#global-s-result).

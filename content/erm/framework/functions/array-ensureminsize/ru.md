## Назначение {#purpose}

Увеличивает массив до minSize при необходимости и заполняет новые элементы. Никогда не уменьшает размер.

## Контракт вызова {#signature}

```erm
!!FU(Array_EnsureMinSize):P(list)/(minSize)/(fillValue);
```

## Порядок параметров {#parameters}

| Позиция | Имя в исходнике | Использование |
| --- | --- | --- |
| x1 | `list` | вход |
| x2 | `minSize` | вход |
| x3 | `fillValue` | вход |

## Состояние и зависимости {#context}

Именованные глобальные переменные в теле не используются.

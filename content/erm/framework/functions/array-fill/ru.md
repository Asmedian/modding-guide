## Назначение {#purpose}

Заполняет целочисленный массив арифметической последовательностью startValue, startValue+step…; step по умолчанию 0. Диапазон включительный, по умолчанию весь массив. Реализация пишет 32-битные значения: строковый массив не передавайте.

## Контракт вызова {#signature}

```erm
!!FU(Array_Fill):P(list)/(startValue)/(step)/(startInd)/(endInd);
```

## Порядок параметров {#parameters}

| Позиция | Имя в исходнике | Использование |
| --- | --- | --- |
| x1 | `list` | вход |
| x2 | `startValue` | вход |
| x3 | `step` | вход |
| x4 | `startInd` | выход / изменяемый |
| x5 | `endInd` | выход / изменяемый |

## Состояние и зависимости {#context}

Именованные глобальные переменные в теле не используются.

Вызовы экспорта: `Erm_FillInt32Array`.

## Назначение {#meaning}

Группа **Win32 API** из поставляемого Framework. Имена и значения ниже соответствуют определениям `!#DC` в предоставленных файлах. Константа подставляется в ERM как `(NAME)`; она не выделяет переменную.

## Значения {#values}

| Константа | Значение |
| --- | --- |
| `INVALID_HANDLE_VALUE` {#const-invalid-handle-value} | `-1` |
| `INVALID_FILE_ATTRIBUTES` {#const-invalid-file-attributes} | `-1` |
| `FILE_ATTRIBUTE_DIRECTORY` {#const-file-attribute-directory} | `16` |

## Назначение {#meaning}

Группа **Команды диалогов** из поставляемого Framework. Имена и значения ниже соответствуют определениям `!#DC` в предоставленных файлах. Константа подставляется в ERM как `(NAME)`; она не выделяет переменную.

## Значения {#values}

| Константа | Значение |
| --- | --- |
| `DLG_CMD_SET_TEXT` {#const-dlg-cmd-set-text} | `3` |
| `DLG_CMD_SET_DEF_FRAME` {#const-dlg-cmd-set-def-frame} | `4` |
| `DLG_CMD_SET_DEF` {#const-dlg-cmd-set-def} | `9` |
| `DLG_CMD_SET_PCX` {#const-dlg-cmd-set-pcx} | `11` |
| `DLG_CMD_TYPE_DEFAULT` {#const-dlg-cmd-type-default} | `512` |

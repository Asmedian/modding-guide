## Назначение {#meaning}

Группа **Выравнивание текста** из поставляемого Framework. Имена и значения ниже соответствуют определениям `!#DC` в предоставленных файлах. Константа подставляется в ERM как `(NAME)`; она не выделяет переменную.

## Значения {#values}

| Константа | Значение |
| --- | --- |
| `TEXT_ALIGN_LEFT` {#const-text-align-left} | `0` |
| `TEXT_ALIGN_CENTER` {#const-text-align-center} | `1` |
| `TEXT_ALIGN_RIGHT` {#const-text-align-right} | `2` |
| `TEXT_ALIGN_TOP` {#const-text-align-top} | `0` |
| `TEXT_ALIGN_MIDDLE` {#const-text-align-middle} | `4` |
| `TEXT_ALIGN_BOTTOM` {#const-text-align-bottom} | `8` |

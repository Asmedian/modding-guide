## Назначение {#meaning}

Группа **Логические значения** из поставляемого Framework. Имена и значения ниже соответствуют определениям `!#DC` в предоставленных файлах. Константа подставляется в ERM как `(NAME)`; она не выделяет переменную.

## Значения {#values}

| Константа | Значение |
| --- | --- |
| `TRUE` {#const-true} | `1` |
| `FALSE` {#const-false} | `0` |
| `NULL` {#const-null} | `0` |
| `DUMMY` {#const-dummy} | `0` |

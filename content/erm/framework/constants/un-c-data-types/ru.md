## Назначение {#meaning}

Группа **Типы данных UN:C** из поставляемого Framework. Имена и значения ниже соответствуют определениям `!#DC` в предоставленных файлах. Константа подставляется в ERM как `(NAME)`; она не выделяет переменную.

## Значения {#values}

| Константа | Значение |
| --- | --- |
| `UNC_UINT8` {#const-unc-uint8} | `-1` |
| `UNC_INT8` {#const-unc-int8} | `1` |
| `UNC_UINT16` {#const-unc-uint16} | `-2` |
| `UNC_INT16` {#const-unc-int16} | `2` |
| `UNC_UINT32` {#const-unc-uint32} | `-4` |
| `UNC_INT32` {#const-unc-int32} | `4` |
| `UNC_INT` {#const-unc-int} | `4` |
| `UNC_UINT` {#const-unc-uint} | `4` |

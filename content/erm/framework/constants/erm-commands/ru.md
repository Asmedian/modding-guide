## Назначение {#meaning}

Группа **Параметры ERM-команд** из поставляемого Framework. Имена и значения ниже соответствуют определениям `!#DC` в предоставленных файлах. Константа подставляется в ERM как `(NAME)`; она не выделяет переменную.

## Значения {#values}

| Константа | Значение |
| --- | --- |
| `M_AUTO_ID` {#const-m-auto-id} | `-1` |
| `M_INT` {#const-m-int} | `0` |
| `M_STR` {#const-m-str} | `1` |
| `M_STORED` {#const-m-stored} | `1` |
| `M_TEMP` {#const-m-temp} | `0` |
| `M_TRIGGER_LOCAL` {#const-m-trigger-local} | `-1` |
| `ARG_SYNTAX_GET` {#const-arg-syntax-get} | `0` |
| `ARG_SYNTAX_SET` {#const-arg-syntax-set} | `1` |
| `ARG_SYNTAX_ADD` {#const-arg-syntax-add} | `2` |

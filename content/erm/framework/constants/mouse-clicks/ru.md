## Назначение {#meaning}

Группа **Флаги мыши** из поставляемого Framework. Имена и значения ниже соответствуют определениям `!#DC` в предоставленных файлах. Константа подставляется в ERM как `(NAME)`; она не выделяет переменную.

## Значения {#values}

| Константа | Значение |
| --- | --- |
| `NO_MOUSE_FLAGS` {#const-no-mouse-flags} | `0` |
| `MOUSE_FLAG_SHIFT` {#const-mouse-flag-shift} | `1` |
| `MOUSE_FLAG_CTRL` {#const-mouse-flag-ctrl} | `4` |
| `MOUSE_FLAG_ALT` {#const-mouse-flag-alt} | `32` |
| `MOUSE_FLAG_RMB` {#const-mouse-flag-rmb} | `512` |

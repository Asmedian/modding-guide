## Назначение {#meaning}

Группа **Действия диалогов** из поставляемого Framework. Имена и значения ниже соответствуют определениям `!#DC` в предоставленных файлах. Константа подставляется в ERM как `(NAME)`; она не выделяет переменную.

## Значения {#values}

| Константа | Значение |
| --- | --- |
| `DLG_ACTION_HOVER` {#const-dlg-action-hover} | `4` |
| `DLG_ACTION_INDLG_CLICK` {#const-dlg-action-indlg-click} | `512` |
| `DLG_ACTION_OUTDLG_CLICK` {#const-dlg-action-outdlg-click} | `8` |
| `DLG_ACTION_MOUSE_WHEEL` {#const-dlg-action-mouse-wheel} | `522` |

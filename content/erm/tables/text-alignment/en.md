## Purpose {#meaning}

DL template Text values select vertical and horizontal positioning inside the item rectangle.

## Values {#values}

| Value | Position |
| --- | --- |
| -1 / 3 | Top / left |
| 1 | Top / center |
| 2 | Top / right |
| 4 / 7 | Middle / left |
| 5 | Middle / center |
| 6 | Middle / right |
| 8 / 0 | Bottom / left |
| 9 | Bottom / center |
| 10 | Bottom / right |

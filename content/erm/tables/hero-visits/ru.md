## Назначение {#meaning}

HE:V использует индекс вида посещения, а не тип объекта карты.

## Значения {#values}

| ID | Значение |
| --- | --- |
| `0` | Камень знаний — объект 100 |
| `1` | Башня Марлетто — 23 |
| `2` | Сад откровения — 32 |
| `3` | Лагерь наёмников — 51 |
| `4` | Звёздная ось — 61 |
| `5` | Древо знаний — 102 |
| `6` | Библиотека — 41 |
| `7` | Арена — 4 |
| `8` | Школа магии — 47 |
| `9` | Школа войны — 107 |

## Применимость {#limits}

HE:R7 работает с маской битов, не с этим списком. В ней бит 18 означает нахождение в лодке; искусственная установка на суше приводит к аварии. Биты 22/23 — максимум удачи/морали, 24 — эффект WOGSHADOWFAX. Не меняйте неизвестные биты 17/19/30/31.

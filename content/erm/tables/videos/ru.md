## Назначение {#meaning}

ID ролика и имя BIK без расширения. Знак + разделяет последовательность фрагментов, а не часть имени файла.

## Значения {#values}

| ID | BIK | Назначение |
| --- | --- | --- |
| 0 | `win3` | Победа в битве |
| 1 | `losecstl + losecslp` | Потеря замка |
| 2 | `rtstart + rtloop` | Сбежать |
| 3 | `surrender` | Сдаться |
| 4 | `defendall + defendloop` | Выстоять при осаде замка |
| 5 | `lbstart + lbloop` | проиграть бой |

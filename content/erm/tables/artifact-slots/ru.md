## Назначение {#meaning}

Позиция на кукле героя, категория UN:A и слот HE:Y2 используют разные нумерации.

## Значения {#values}

| ID | Значение |
| --- | --- |
| `0` | Голова |
| `1` | Плечи |
| `2` | Шея |
| `3` | Правая рука |
| `4` | Левая рука |
| `5` | Торс |
| `6` | Правое кольцо |
| `7` | Левое кольцо |
| `8` | Ноги |
| `9` | Разное 1 |
| `10` | Разное 2 |
| `11` | Разное 3 |
| `12` | Разное 4 |
| `13` | Баллиста |
| `14` | Тележка |
| `15` | Палатка |
| `16` | Катапульта |
| `17` | Книга |
| `18` | Разное 5 |
| `19..82` | Рюкзак |

## Применимость {#limits}

Для UN:A категории 0 — только рюкзак, 1..6 — голова/плечи/шея/правая рука/левая рука/торс, 7 любое кольцо, 8 ноги, 9 разное, 10..12 машины, 13 катапульта, 14 книга. HE:Y2: 0..5 как кукла, 6 любое кольцо, 7 ноги, 8 разное, 9..11 машины, 12 катапульта (в старой справке помечено неопределённым), 13 книга; 14+ недопустимы. Не переносите необычные составные значения AP2 в другой слот без проверки.

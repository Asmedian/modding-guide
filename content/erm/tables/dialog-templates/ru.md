## Формат таблицы {#format}

Таблица разделяется табуляциями, содержит не менее 14 столбцов. Первые две строки и столбец 0 игнорируются. Не удаляйте пустые завершающие колонки: подсказка занимает отдельное поле. Строка # в столбце 1 начинает диалог или завершает предыдущий.

## Заголовок диалога {#header}

Столбцы: 1 `#`, 2 уникальный ID, 3 X, 4 Y (-1 центр), 5 ширина, 6 высота, 7 максимальное число элементов, 8 цвет игрока (-1 текущий), 9 PCX фона (пусто — стандартный фон), 10 ID элемента для вывода подсказки.

## Элементы {#items}

У всех обычных элементов: 1 тип, 2 ID, 3 X, 4 Y, 5 ширина, 6 высота. Далее:

| Тип | Последующие поля |
| --- | --- |
| P | PCX, флаг 2048, подсказка |
| D | DEF, кадр, флаг 16, подсказка |
| B | DEF, код горячей клавиши, подсказка |
| T | текст, шрифт, цвет, фон, выравнивание, флаг 8, подсказка |
| S | текст, шрифт, цвет, цвет прокрутки (0 обычный/иное синий), подсказка |
| E | текст, шрифт, подсказка |
| V | поле 5: внутренний ID видео; размеров и подсказки нет |

Анимированный тип A в старом формате не поддерживается.

## Поведение элементов {#constraints}

DEF кнопки должен иметь минимум два кадра: второй используется при нажатии и отключении. Элемент 30721 закрывает окно по Escape. Видео только одно, поверх остальных элементов; оно должно помещаться в окно. Подсказка S в старом формате работает при ID=-1. Разные файлы не должны повторять ID диалогов.

## Когда срабатывает и аргументы {#event}

После завершения сохранения. Аргументов нет. Для записи собственной секции данных используйте OnSavegameWrite.

## Объявление {#declaration}

```erm
!?FU(OnAfterSaveGame);
```

## Идентификатор и совместимость {#identity}

ID `77008`; регистрация `TRIGGER_AFTER_SAVE_GAME`. Имя подтверждено предоставленным исходником ERA. Историческая версия появления здесь не приписывается без отдельного подтверждения. Для нового скрипта используйте имя события, числовой ID оставлен для сопоставления старого кода.

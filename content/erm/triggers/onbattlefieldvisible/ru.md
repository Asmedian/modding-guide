## Когда срабатывает и аргументы {#event}

После запуска темы боя и диалога тактики. Аргументов нет. Это момент видимости, а не гарантия завершения расстановки тактики.

## Объявление {#declaration}

```erm
!?FU(OnBattlefieldVisible);
```

## Идентификатор и совместимость {#identity}

ID `77020`; регистрация `TRIGGER_BATTLEFIELD_VISIBLE`. Имя подтверждено предоставленным исходником ERA. Историческая версия появления здесь не приписывается без отдельного подтверждения. Для нового скрипта используйте имя события, числовой ID оставлен для сопоставления старого кода.

## Когда срабатывает и аргументы {#event}

x1 — стек 0..41; x2 — адрес его структуры; x3 — запрет штатной фазы (0/1, изменяемый). Указатель действует только в текущем бою. Для изменения количества лечения используйте отдельное OnBattleStackRegeneration.

## Объявление {#declaration}

```erm
!?FU(OnBattleRegeneratePhase);
```

## Идентификатор и совместимость {#identity}

ID `77007`; регистрация `TRIGGER_REGENERATE_PHASE`. Имя подтверждено предоставленным исходником ERA. Историческая версия появления здесь не приписывается без отдельного подтверждения. Для нового скрипта используйте имя события, числовой ID оставлен для сопоставления старого кода.

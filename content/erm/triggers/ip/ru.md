## Триггер IP {#ref-tr-ip}

:::erm
<section class="erm-reference" lang="ru">
<div><div class="erm-align-center erm-paragraph">
<span class="erm-source-title">Триггер <strong>IP</strong> (поддержка <strong>с</strong>етевой <strong>и</strong>гры)</span></div>
<div class="erm-paragraph">
<strong><span class="erm-anchor" id="ref-tr-ip-red"></span><span class="erm-tone-red">!?IP#;</span> - мультиплеерная поддержка</strong></div>
<div class="erm-paragraph">Если один герой игрока атакует другого героя игрока, произойдут следующие действия:
</div><ol>
<li>Триггер <a href="../ba/#ref-tr-ba">!?BA0</a> включится для атакующего игрока</li>
<li>Триггер <strong>!?IP0</strong> включится для атакующего игрока</li>
<li>Передача информации защищающемуся игроку:<br>
 - информация о атакующем герое<br>
 - информация о командире атакующего героя<br>
 - установленные <em>v</em>-переменные v9001-v10000<br>
 - все потенциальные изменения параметров монстров</li>
<li>Вся отправленная информация принимается защищающимся игроком</li>
<li>Триггер <strong>!?IP1</strong> включается для защищающегося игрока</li>
<li>Триггер <a href="../ba/#ref-tr-ba">!?BA0</a> включается для защищающегося игрока.<br>
<span class="erm-anchor" id="ref-tr-ip-bold"></span><em class="erm-strong">Замечание:</em> справедливо только для режима "Hot Seat" – при игре на разных ПК срабатывает лишь <a href="../ba/#ref-tr-ba">!?BA52</a>.</li>
</ol>
<div class="erm-paragraph"><strong>Происходит бой.</strong></div>

<div class="erm-paragraph">Если <strong>атакующий</strong> игрок <strong>выигрывает</strong>, то конец.</div>

<div class="erm-paragraph">Если <strong>выигрывает</strong> <strong>защищающийся</strong> игрок, переход к следующей секции:
</div><ol>
<li>Атакующий игрок ждёт, пока защищающийся получит уровни</li>
<li>Герой защищающегося игрока и командир получают уровни</li>
<li>Триггер <strong>!?IP2</strong> включается для защитившегося игрока</li>
<li>Передача информации атакующему игроку:<br>
 - значения вторичных навыков защитившегося героя (все 28), уровень и опыт<br>
 - информация о командире защитившегося героя (полностью)<br>
 - установленные <em>v</em>-переменные v9001-v10000</li>
<li>Триггер <a href="../ba/#ref-tr-ba">!?BA1</a> включается для защитившегося игрока</li>
<li>Атаковавший игрок ждёт окончания получения уровней защитившимся</li>
<li>Вся информация принимается атакующим игроком</li>
<li>Триггер <strong>!?IP3</strong> включается для атакующего игрока</li>
<li>Триггер <a href="../ba/#ref-tr-ba">!?BA1</a> включается для атакующего игрока.</li>
</ol>
<div class="erm-paragraph">Таким образом, армия, герои и командиры синхронизируются на всех компьютерах.</div>

</div>
</section>
:::

## Когда срабатывает {#event}

0 перед отправкой начальных данных атакующим, 1 после их получения защитником; 2 перед отправкой итогов, 3 после их получения. IP предоставляет дополнительную синхронизацию.

## Объявление {#syntax}

```erm
!?IP0; / !?IP1; / !?IP2; / !?IP3;
```

## Ограничения и порядок {#limits}

Контекст зависит от стороны и результата боя. Локальные клики игрока не воспроизводятся автоматически на другом ПК; Hot Seat не эквивалентен сетевой игре.

## Когда срабатывает и аргументы {#event}

Контекст мыши доступен через CM. Событие интерфейсное и локальное; оно не является сетевой синхронизацией действия.

## Объявление {#declaration}

```erm
!?FU(OnKingdomOverviewMouseClick);
```

## Идентификатор и совместимость {#identity}

ID `77027`; регистрация `TRIGGER_KINGDOM_OVERVIEW_MOUSE_CLICK`. Имя подтверждено предоставленным исходником ERA. Историческая версия появления здесь не приписывается без отдельного подтверждения. Для нового скрипта используйте имя события, числовой ID оставлен для сопоставления старого кода.

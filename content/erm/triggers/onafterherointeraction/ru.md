## Когда срабатывает и аргументы {#event}

x1 — инициатор; x2 — целевой герой. Состояние после взаимодействия может отличаться: герой мог погибнуть или сменить владельца.

## Объявление {#declaration}

```erm
!?FU(OnAfterHeroInteraction);
```

## Идентификатор и совместимость {#identity}

ID `77011`; регистрация `TRIGGER_AFTERHEROINTERACT`. Имя подтверждено предоставленным исходником ERA. Историческая версия появления здесь не приписывается без отдельного подтверждения. Для нового скрипта используйте имя события, числовой ID оставлен для сопоставления старого кода.

## Ресурсы SoD {#resources}

Категории взяты из `H3bitmap.lf` и `H3sprite.lf`; ресурсы извлечены из `H3bitmap.lod`, `H3sprite.lod`, `Heroes3.snd` и `VIDEO.VID`. Метка **SoD** обозначает происхождение каждого раздела. TXT пока пропущены.

На страницах показаны отдельные малые WebP-превью. Полный DEF, звук или видео загружается только после нажатия. Одновременно активен один проигрыватель; его начальная громкость — 50%. DEF открывается по группам с исходными названиями кадров. Для звуков сохранены частота дискретизации и порядок отсчётов, для видео — частота и число кадров. DEF не содержит таймингов; регулируемый интервал предпросмотра по умолчанию — 100 мс.

Шрифты показаны таблицей глифов, палитры — сеткой цветов. Маски открываются кнопкой «Показать маску объекта» рядом с соответствующим DEF. Кампании открываются с описаниями, сценариями, мини-картами и экспортом H3M. Для XMI и IFR доступен байтовый просмотр.
